# インストーラの入手と使い方

このページは **プログラミングの知識が無い方** 向けです。

JP PII Mask（ジェイピー・ピーアイアイ・マスク）は、
AI に文章を送るときに個人情報を自動で隠し、返ってきた文章で元に戻す道具です。
このページでは、**アプリのインストーラを手に入れて、自分のパソコンに入れる** 方法を説明します。

---

## 方法 1: 出来上がったインストーラをダウンロードする（いちばん簡単）

すでにビルド済みのものがある場合は、これを選んでください。

1. ブラウザで GitHub のリポジトリを開きます
2. 上のほうにある **「Releases」**（リリース）をクリックします
3. 使っているパソコンに合うファイルをダウンロードします

| お使いのパソコン | ダウンロードするファイル |
| --- | --- |
| **Windows** | `...-setup.exe`（推奨）または `....msi` |
| **Mac** | `....dmg` |

4. ダウンロードしたファイルをダブルクリックして、画面の指示に従います

**インストールはこれで終わりです。** あとは下の「インストール後の使い方」へ進んでください。

---

## 方法 2: 自分でビルドする（Actions を使う）

ビルド済みのファイルが無い場合は、GitHub 上で自分でビルドできます。
**自分のパソコンに特別な道具を入れる必要はありません。**
GitHub のサーバーが代わりにビルドしてくれます。

1. リポジトリの **「Actions」** タブを開きます
2. 左の一覧から **「build-installers」** をクリックします
3. 右側の **「Run workflow」** というボタンを押し、緑の **「Run workflow」** を押します
4. しばらく待ちます（5〜15 分くらい）

   - `windows-installer` … Windows 用
   - `macos-installer` … Mac 用

5. 自分のパソコンに合うものをクリックしてダウンロードします
6. ダウンロードしたファイルをダブルクリックして、画面の指示に従います

> **うまくいかないとき**
> 「Actions」の画面が赤い × になっていたら、ビルドが失敗しています。
> まずは作成者に連絡してください（このページの下に連絡先の書き方があります）。

---

## 方法 3: 自分のパソコンでビルドする（上級者向け）

自分でコードを触りたい場合や、GitHub を使いたくない場合の方法です。
**Python** が入っている必要があります（https://www.python.org/downloads/ から無料で入れられます）。

### Windows の場合

PowerShell を開いて、リポジトリのフォルダで次を実行します。

```powershell
.\setup_and_build.ps1
```

### Mac の場合

ターミナルを開いて、リポジトリのフォルダで次を実行します。

```bash
bash setup_and_build.sh
```

**これだけです。** 1 つのスクリプトが、次のことをすべて自動で行います。

1. Rust（アプリを組み立てる道具）の確認。無ければ自動で導入
2. Python の確認
3. Python サーバーのビルド（アプリに同梱するため）
4. ソースの検査 ← 最初の関門。ここで失敗すると、原因が表示されます
5. Tauri CLI の確認。無ければ自動で導入
6. アプリとインストーラの作成
7. できあがったファイルの場所を表示

できあがったインストーラはここにあります。

- Windows: `desktop\src-tauri\target\release\bundle\msi\` または `nsis\`
- Mac: `desktop\src-tauri\target\release\bundle\dmg\`

**途中で止まってしまったら:**
メッセージに日本語で対処方法が書かれています。一番多いのは
「Visual Studio Build Tools が入っていない」（Windows の場合）です。
表示されたコマンドをコピーして実行し、もう一度このスクリプトを実行してください。

> **まず型検査だけ試したい場合**
> インストーラまで作らず、アプリが組み立てられるかだけを確かめられます。
>
> ```powershell
> .\setup_and_build.ps1 -CheckOnly
> ```
>
> ```bash
> bash setup_and_build.sh --check-only
> ```

## インストール後の使い方

1. インストールしたアプリを起動します
   - 起動しても画面は出ません（常駐アプリのため）
   - Windows: 画面右下の通知領域、Mac: 画面上部のメニューバーにアイコンが出ます

2. アイコンを**ダブルクリック**すると設定画面が開きます

3. 設定画面で次を入力します
   - **上流 API**: 使っている AI サービスの種類（OpenAI / Anthropic など）
   - **API キー**: AI サービスのキー

4. 設定画面の大きなスイッチで **マスキング保護を ON** にします

5. AI を使うアプリ（Cursor、自作スクリプトなど）の接続先を
   `http://127.0.0.1:8787/v1` に変更します

これで、AI に送られる文章から個人情報が自動的に隠され、
AI からの返事では元の文章に戻ります。

> **アイコンのメニュー**
> - マスキング保護 ON/OFF … 保護の入り切り
> - 設定を開く … 設定画面を表示
> - 終了 … アプリを終了

## よくある質問

**Q. 初回起動時に「発行元が不明です」と警告が出ました**

署名を行っていないためです。次のようにすると起動できます。

- Windows: 「詳細情報」→「実行」を選ぶ
- Mac: アイコンを**右クリック**して「開く」を選ぶ

**Q. 設定画面が出てきません**

常駐アプリなので、起動しても画面は出ません。
画面右下（Windows）または画面上部（Mac）のアイコンをダブルクリックしてください。

**Q. Mac で「壊れているため開けません」と出ました**

配布したアプリに署名が無いためです。
ターミナルで次を実行すると開けるようになります。

```bash
xattr -dr com.apple.quarantine "/Applications/JP PII Mask.app"
```

**Q. 個人情報はどこかに送られますか**

送られません。マスキングは**あなたのパソコンの中だけ**で行われます。
AI サービスに送られるのは、個人情報を置き換えた記号（`[氏名_1]` など）だけです。
元の文章はあなたのパソコン内の暗号化されたファイルに保管されます。
