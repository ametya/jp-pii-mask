# インストーラの作り方・使い方

このページは **プログラミングの知識が無い方** 向けです。

JP PII Mask（ジェイピー・ピーアイアイ・マスク）は、
AI に文章を送るときに個人情報を自動で隠し、返ってきた文章で元に戻す道具です。
このページでは、**アプリを自分のパソコンに用意する** 方法を説明します。

---

## 方法 1: 出来上がったものをダウンロードする（いちばん簡単）

すでに配布されているものがある場合は、これを選んでください。
**何もインストールする必要はありません。**

1. ブラウザで GitHub のリポジトリを開きます
2. 上のほうにある **「Releases」**（リリース）をクリックします
3. 使っているパソコンに合うファイルをダウンロードします

| お使いのパソコン | ダウンロードするファイル |
| --- | --- |
| **Windows** | `...-setup.exe`（推奨）または `....msi` |
| **Mac** | `....dmg` |

4. ダウンロードしたファイルをダブルクリックして、画面の指示に従います

**これで終わりです。** あとは下の「インストール後の使い方」へ進んでください。

---

## 方法 2: 自分で作る — ファイルをダブルクリックするだけ（Windows / Mac）

配布されているものが無い場合は、自分のパソコンで作れます。

リポジトリのフォルダにある、次のファイルを**ダブルクリックするだけ**です。

| お使いのパソコン | ダブルクリックするファイル |
| --- | --- |
| **Windows** | `インストーラを作る.bat` |
| **Mac** | `インストーラを作る.command` |

あとは自動で最後まで進みます。黒い画面（ターミナル）が開いて、
進み具合が日本語で表示されます。終わるまでそのままお待ちください。

- **初回は数分〜十数分かかります。** 途中で止めないでください。
- 初回は「組み立てに必要な道具」（Rust）を自動でダウンロードして入れます。
  そのため、数百 MB の通信が発生します。
- 途中でパソコンが「このアプリを実行しますか？」と聞いてきたら、許可してください。

終わると、黒い画面の最後に **「できあがったファイル」** として
インストーラの場所が表示されます。そこに書かれたファイルをダブルクリックすれば
インストールできます。

> **Python が必要です**
> 上記のファイルを開いたときに
> 「Python was not found / Python が見つかりませんでした」
> と表示された場合は、先に Python を入れてください。
> **無料**です。https://www.python.org/downloads/ からインストールし、
> インストール画面の **「Add python.exe to PATH」** に必ずチェックを入れてください。
> 入れたあと、もう一度このファイルをダブルクリックしてください。
>
> Mac の場合、最初に開いたときに「コマンドラインツールを入れますか？」と
> 聞かれたら「はい」を選んでください。

> **止めてしまった / 失敗したとき**
> もう一度同じファイルをダブルクリックすれば、続きから進みます。
> 一度ダウンロードしたものは再利用されます。

## 方法 3: GitHub に作ってもらう（自分のパソコンに何も入れずに作る）

自分のパソコンに道具を入れたくない場合は、
GitHub のサーバーに作ってもらう方法もあります。

1. リポジトリの **「Actions」** タブを開きます
2. 左の一覧から **「build-installers」** をクリックします
3. 右側の **「Run workflow」** を押し、緑の **「Run workflow」** を押します
4. しばらく待ちます（5〜15 分くらい）

   - `windows-installer` … Windows 用
   - `macos-installer` … Mac 用

5. 自分のパソコンに合うものをクリックしてダウンロードします
6. ダウンロードしたファイルをダブルクリックして、画面の指示に従います

> **うまくいかないとき**
> 「Actions」の画面が赤い × になっていたら、作成に失敗しています。
> まずは作成者に連絡してください。

## 方法 4: コマンドで実行したい場合（上級者向け）

すでにターミナルに慣れている方向けです。やりたいことは方法 2 と同じです。

```bash
# リポジトリのルートで
python desktop/scripts/build-installer.py

# アプリを組み立てられるかだけ確認する（インストーラは作らない）
python desktop/scripts/build-installer.py --check-only

# 内蔵サーバーを作り直さない（既にある場合）
python desktop/scripts/build-installer.py --skip-sidecar
```

できあがったファイルの場所:

- Windows: `desktop\src-tauri\target\release\bundle\msi\` または `nsis\`
- Mac: `desktop\src-tauri\target\release\bundle\dmg\`

## インストール後の使い方

1. インストールしたアプリを起動します
   - 起動しても画面は出ません（常駐アプリのため）
   - Windows: 画面右下の通知領域、Mac: 画面上部のメニューバーにアイコンが出ます

2. アイコンを**ダブルクリック**すると設定画面が開きます

3. 設定画面で次を入力します
   - **上流 API**: 使っている AI サービスの種類（OpenAI / Anthropic など）
   - **API キー**: AI サービスのキー

4. 設定画面の大きなスイッチで **マスキング保護を ON** にします

5. AI を使うアプリ（Cursor、自作スクリプトなど）の接続先を
   `http://127.0.0.1:8787/v1` に変更します

これで、AI に送られる文章から個人情報が自動的に隠され、
AI からの返事では元の文章に戻ります。

> **アイコンのメニュー**
> - マスキング保護 ON/OFF … 保護の入り切り
> - 設定を開く … 設定画面を表示
> - 終了 … アプリを終了

## よくある質問

**Q. 初回起動時に「発行元が不明です」と警告が出ました**

署名を行っていないためです。次のようにすると起動できます。

- Windows: 「詳細情報」→「実行」を選ぶ
- Mac: アイコンを**右クリック**して「開く」を選ぶ

**Q. 設定画面が出てきません**

常駐アプリなので、起動しても画面は出ません。
画面右下（Windows）または画面上部（Mac）のアイコンをダブルクリックしてください。

**Q. Mac で「壊れているため開けません」と出ました**

配布したアプリに署名が無いためです。
ターミナルで次を実行すると開けるようになります。

```bash
xattr -dr com.apple.quarantine "/Applications/JP PII Mask.app"
```

**Q. 作っている途中で「リンカが見つかりません」のようなエラーが出ました（Windows）**

アプリを組み立てるための道具（Visual Studio Build Tools）が足りません。
黒い画面に出ているコマンドをそのままコピーして実行し、
もう一度 `インストーラを作る.bat` をダブルクリックしてください。

**Q. 個人情報はどこかに送られますか**

送られません。マスキングは**あなたのパソコンの中だけ**で行われます。
AI サービスに送られるのは、個人情報を置き換えた記号（`[氏名_1]` など）だけです。
元の文章はあなたのパソコン内の暗号化されたファイルに保管されます。
